# 🎬 Netflix Data Analysis

A Data Science project built using **Python, Pandas, and Matplotlib** to perform Exploratory Data Analysis (EDA) on Netflix content and generate meaningful insights through professional visualizations.

---

## 📌 Project Overview

This project analyzes the Netflix Titles dataset to understand content distribution, release trends, countries, genres, and ratings.

The project also generates charts and a summary report automatically.

---

## 🚀 Features

- 📊 Exploratory Data Analysis (EDA)
- 🎬 Movies vs TV Shows Analysis
- 🌍 Top Countries Analysis
- 📅 Release Year Trend
- ⭐ Rating Distribution
- 🎭 Top Genres Analysis
- 📈 Professional Data Visualizations
- 📄 Automatic Report Generation
